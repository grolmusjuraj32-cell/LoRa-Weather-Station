# LoRa-Weather-Station
Weather station using LoRa wireless communication

Design and implement a modular system for wireless data collection from distributed sensor units using LoRa technology in the 868 MHz frequency band.

Design a central unit based on the RAK3172 module and the ESP32 microcontroller.

Implement data reception from external units and its transfer to the ESP32 via a suitable communication interface.

Design external sensor units using the RAK3172 module to measure temperature, humidity, and potentially other environmental parameters.

Implement periodic collection and wireless transmission of measured data at five-minute intervals.

Optimize the power consumption of external units by utilizing low-power modes and controlled power supply to the sensors.

Design battery power systems for the units, including appropriate voltage regulation.

Implement the processing, storage, and visualization of measured data on the central unit's display.

Design a communication protocol that enables the identification of individual units and reliable data transmission.

Experimentally verify the system's functionality, wireless communication range, power consumption, and scalability through the addition of further sensor units.
